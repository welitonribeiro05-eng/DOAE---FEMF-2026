Plataforma web que conecta doadores a ONGs, facilitando a doação de alimentos, roupas, ração e outros itens.

Sobre o projeto

O DOAE nasceu da necessidade de aproximar quem quer doar de quem precisa receber. Muitas pessoas têm itens para doar, mas não sabem para onde enviar, e muitas ONGs têm dificuldade de divulgar suas necessidades. A plataforma faz essa ponte de forma simples.

Projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas (ADS).

Funcionalidades:

[x] Cadastro e login de doadores 
[x] Cadastro e login de ONGs 
[x] Publicação de itens disponíveis para doação 
[x] Publicação de necessidades das ONGs 
[x] Busca e filtro por tipo de item (alimentos, roupas, ração, outros) 
[x] Contato entre doador e ONG 
[ ] Integração com banco de dados

Tecnologias

HTML, CSS e JavaScript
